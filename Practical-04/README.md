# Practical No. 04

## Aim

To develop a simple Android Calculator application that performs basic arithmetic operations such as Addition, Subtraction, Multiplication and Division.

## Description

This practical demonstrates the use of **EditText, Button and TextView** components in Android. The user enters two numbers and selects an arithmetic operation. The calculated result is displayed on the screen.

## Operations

* Addition (+)
* Subtraction (−)
* Multiplication (×)
* Division (÷)

## Files

* `activity_main.xml`
* `MainActivity.java`
* `bg_gradient.xml`
* `edit_bg.xml`
* `button_bg.xml`
* `result_bg.xml`
* `strings.xml`

## Technologies Used

* Android Studio
* Java
* XML
* Android SDK

## Features

* Attractive calculator interface
* Accepts two numbers
* Performs four basic arithmetic operations
* Handles empty input
* Handles division by zero
* Displays the calculation result

## Output

Example:

**First Number:** 25
**Second Number:** 5

**Addition:** 30.0
**Subtraction:** 20.0
**Multiplication:** 125.0
**Division:** 5.0

`com.example.calculator_110`
