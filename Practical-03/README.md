# Practical 03 – Button Click Event

## Aim

To develop an Android application that displays a welcome message when a button is clicked.

## Description

This practical demonstrates the use of a **Button** and **TextView** in Android. When the user clicks the button, the message **"Welcome to Mobile Computing Lab"** is displayed.

## Technologies Used

* Android Studio
* Java
* XML
* Android SDK

## Features

* Simple and attractive user interface
* Button click event
* Displays welcome message
* Uses TextView to show output

## Output

**Button:** Sakshi Click Here

**Message:** Welcome to Mobile Computing Lab

## Package Name

`com.example.demo_surajsanap_110`
